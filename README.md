
# FPGA-Based Cognitive Game System

A hardware-based **Cognitive Game System** designed using **Xilinx Vivado** for FPGA implementation.  
The project focuses on building a digital game that can test and improve basic cognitive skills such as memory, attention, reaction, and decision-making through FPGA-based logic.

---

## Project Overview

The main goal of this project is to design a simple cognitive/brain-training game using digital logic instead of a normal software application. The game logic is implemented for an FPGA, where user input, game state, output display, score handling, and timing are controlled by hardware logic.

This project was developed as an FPGA/Vivado project and includes synthesis, implementation, simulation, and bitstream generation files. The generated bitstream file indicates that the design was successfully implemented and prepared for programming on a supported FPGA board.

## Main Features

### 1. Hardware-Based Game Logic

The project implements the game logic using FPGA digital design. Unlike a software game, the game behavior is controlled by hardware-level logic such as registers, counters, states, and combinational/sequential circuits.

---

### 2. User Input Handling

The system is designed to take input from FPGA board controls such as buttons or switches. These inputs can be used by the player to respond to the game challenge.

Possible input actions include:

- Starting the game
- Selecting an answer or option
- Responding to a displayed pattern
- Resetting the game

---

### 3. Cognitive Skill Testing

The game is related to cognitive skill improvement. It can be used to test and practice:

- Memory
- Attention
- Reaction speed
- Pattern recognition
- Decision-making ability

---

### 4. Output Display

The output can be shown using FPGA board output devices such as:

- LEDs
- Seven-segment display
- On-board indicators
- Other configured output pins

The display/output section helps the player understand the current game state, response result, or score.

---

### 5. Clock and Reset Control

The design uses FPGA clock and reset signals to control timing and system initialization.

The clock signal helps the game operate step by step, while the reset signal returns the system to its initial state.

---

### 6. Simulation Support

The project includes simulation-related files generated by Vivado/XSim. Simulation is used to verify the behavior of the design before programming the FPGA board.

Simulation helps check whether:

- Inputs are working properly
- Game states are changing correctly
- Output signals are produced correctly
- Timing behavior is correct

---

### 7. Synthesis and Implementation

The project includes Vivado synthesis and implementation run files. This means the design was processed through the FPGA design flow.

The design flow includes:

1. HDL design creation
2. Simulation
3. Synthesis
4. Implementation
5. Bitstream generation
6. FPGA board programming

---

### 8. Bitstream Generation

The project contains a generated bitstream file:

```text
cognitive_game.runs/impl_1/top.bit
```

This file can be used to program the FPGA board if the target board and constraints are correctly configured.

## How to Open the Project in Vivado

### Step 1: Install Vivado

Install Xilinx Vivado on your computer.

Recommended version: use the same or a compatible Vivado version that was used to create the original project.

---

### Step 2: Open Vivado

Open **Xilinx Vivado**.

---

### Step 3: Open the Project

If the project contains a `.xpr` file, open it using:

```text
File > Open Project
```

Then select the `.xpr` file.

If there is no `.xpr` file, create a new Vivado project and manually add:

- HDL source files
- Testbench files
- Constraint `.xdc` file

---

### Step 4: Run Simulation

To verify the design:

```text
Flow Navigator > Run Simulation > Run Behavioral Simulation
```

This checks the logic before uploading it to hardware.

---

### Step 5: Run Synthesis

```text
Flow Navigator > Run Synthesis
```

Synthesis converts the HDL code into FPGA-level logic.

---

### Step 6: Run Implementation

```text
Flow Navigator > Run Implementation
```

Implementation places and routes the design inside the FPGA.

---

### Step 7: Generate Bitstream

```text
Flow Navigator > Generate Bitstream
```

This creates the `.bit` file needed to program the FPGA board.

---

### Step 8: Program FPGA Board

Connect the FPGA board to your computer and open:

```text
Open Hardware Manager > Open Target > Auto Connect > Program Device
```

Then select the generated bitstream file:

```text
top.bit
```

## How the Game Works

The cognitive game follows a simple hardware-controlled flow:

1. The system starts from an initial/reset state.
2. The game displays a challenge or pattern through output devices.
3. The player gives input using buttons or switches.
4. The FPGA checks whether the input is correct.
5. The system updates the result, score, or next state.
6. The game continues until reset or completion.

---

## Concepts Used

### 1. Finite State Machine

The game logic can be controlled using a finite state machine. Each state represents a specific stage of the game, such as start, display, input, checking, score update, and game over.

---

### 2. Sequential Logic

Sequential logic is used for storing values that change with the clock, such as:

- Current state
- Score
- Timer value
- User response

---

### 3. Combinational Logic

Combinational logic is used to decide outputs based on current inputs and states.

---

### 4. Counter and Timer Logic

Counters can be used to control delays, display time, response time, and game timing.

---

### 5. Input and Output Interfacing

The project connects FPGA input pins and output pins to external or on-board components such as switches, buttons, LEDs, or displays.
